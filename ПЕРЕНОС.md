# Перенос приложения «Раппорт: ЖиваЯ»

Этот архив — полный код приложения. Его можно положить в GitHub и запустить
на любом сервере, где установлен Node.js.

В архиве: код (`src/`), настройки сборки, зависимости (`package.json`,
`bun.lock`), тесты и папка `assets-original/` с тремя исходными картинками.

---

## 1. Запустить у себя

Нужен Node.js 20 или новее.

```sh
npm install
npm run dev        # режим разработки, правки видны сразу
npm run build      # сборка готовой версии
npm run preview    # посмотреть собранную версию
npm run test       # проверки (7 штук)
```

Приложение не статическое: в нём есть серверная часть (`src/server.ts`),
поэтому на хостинге нужен Node.js, а не только папка с файлами.
Точную команду запуска собранной версии уточним в момент переноса —
здесь сборку мы не запускали.

---

## 2. Картинки — главное, что нужно поменять при переносе

Сейчас в коде лежат не сами картинки, а ссылки на хранилище Lovable
(вида `/__l5e/assets-v1/...`). **Вне Lovable эти ссылки не работают** —
карточки будут без обложек.

Чтобы картинки стали частью проекта:

1. Скопируй три файла из `assets-original/` в `src/assets/`:
   - `devochka_vnutri_cover.png` — обложка карты «Девочка внутри»
   - `rapport_box.webp` — фото коробки на стартовом экране
   - `rapport_cards.webp` — фото карт на финальном экране
2. Замени импорт в `src/lib/cards.ts`:
   ```ts
   // было
   import devochkaCover from "@/assets/devochka_vnutri_cover.png.asset.json";
   // станет
   import devochkaCover from "@/assets/devochka_vnutri_cover.png";
   ```
   и в том же файле замени `cover: devochkaCover.url` на `cover: devochkaCover`.
3. Замени импорты в `src/routes/index.tsx`:
   ```ts
   // было
   import box from "@/assets/rapport_box.webp.asset.json";
   import cardsPhoto from "@/assets/rapport_cards.webp.asset.json";
   // станет
   import box from "@/assets/rapport_box.webp";
   import cardsPhoto from "@/assets/rapport_cards.webp";
   ```
   и в этом файле замени `box.url` на `box`, `cardsPhoto.url` на `cardsPhoto`.
4. Файлы-указатели `*.asset.json` из `src/assets/` после этого можно удалить.

Типы для импорта картинок уже настроены (`vite/client` в `tsconfig.json`),
так что проверка типов на эти правки не обидится.

## 3. Шрифты

Игра берёт шрифты «Cormorant Garamond» и «Manrope» с Google Fonts —
это видно в `src/routes/__root.tsx` (строки со `fonts.googleapis.com`).
На российском сервере или в российском же интернете эти шрифты могут
грузиться медленно или не грузиться вовсе.

Надёжнее: скачать оба шрифта файлами, положить в `public/fonts/`,
подключить через `@font-face` в `src/styles.css` и убрать два тега
`<link>` с Google Fonts из `src/routes/__root.tsx`.

## 4. Чего в этом коде нет

- **Нет базы данных и входов в аккаунт.** Прогресс сезона и ответы
  участницы лежат в браузере того устройства, где она играла
  (`src/lib/season-store.ts`, ключ `rapport-season-1`). С другого телефона
  её ответы не появятся.
- **Нет оплаты и записи.** Три кнопки на финальном экране
  («Записаться на живую игру», «на онлайн-игру», «Интенсив») сейчас
  намеренно без действия — так договорились.
- **В сезоне открыт только день 1.** Дни 2–14 помечены «Скоро» и откроются,
  когда в `src/lib/cards.ts` появятся настоящие карты.

## 5. Как положить в GitHub

**Вариант А — через Lovable (проще, сохраняет синхронизацию).**
В Lovable: Project settings → Git → подключить GitHub. Lovable сам создаст
приватный репозиторий и будет коммитить туда каждое изменение.
Картинки при этом останутся на хранилище Lovable, а в репозиторий попадут
файлы-указатели — то есть для чужого сервера нужно будет сделать правку из
раздела 2.

**Вариант Б — вручную из этого архива.**
```sh
unzip rapport-code.zip -d rapport
cd rapport
git init && git add -A && git commit -m "Раппорт ЖиваЯ: первый перенос"
git branch -M main
git remote add origin <адрес твоего репозитория>
git push -u origin main
```
Этот вариант сразу даёт самодостаточный код: картинки внутри, ничего не
ссылается на Lovable.
